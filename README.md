# Study Quest（学習・復習ナビ）試作版

「かわいい育成ゲーム＋学習・復習ナビ」を組み合わせた、iPhone向けPWA試作版です。

## 主な機能
- 今日の復習対象を優先度順に表示
- ◎ / ○ / △ / × の4段階で結果入力
- 結果に応じてXP加算・レベルアップ
- レベルで「おへや」のアイテムを解放
- 連続学習日数・バッジ
- A/B/Cレベル管理
- 保護者ビュー（直し待ち、A未処理、要注意単元）
- 問題追加
- JSONバックアップの書き出し / 読み込み
- オフラインキャッシュ（PWA）

## iPhoneで使う一番簡単な方法：GitHub Pages
1. ZIPを展開する
2. GitHubで新しいリポジトリを作る
3. ZIP内のファイル・フォルダをすべてリポジトリ直下へアップロード
4. GitHubの `Settings` → `Pages`
5. `Build and deployment` の Source を `Deploy from a branch`
6. Branchを `main`、Folderを `/(root)` にして Save
7. 表示されたGitHub PagesのURLをiPhoneのSafariで開く
8. Safariの共有 →「ホーム画面に追加」

## 注意
- 記録は基本的に各端末のブラウザ内（localStorage）に保存されます。
- iPhoneとPCの自動同期はまだありません。
- SafariのWebサイトデータを消すと記録も消える場合があります。保護者ビューからバックアップできます。
- 初期データは、これまでの相談内容をモデルにした仮データです。実際の成績記録ではありません。

## 実日付による復習管理（v6）
- 各問題に `nextReviewDate`（YYYY-MM-DD）を保存
- 初回に○/◎ → 翌日、以後の○/◎ → 3日後 → 7日後 → 14日後 → 定着
- △/× → 翌日に戻る
- 復習期限を過ぎても「今日のクエスト」に残る
- 期限超過日数を優先度に加点
- 旧版の `today` / `future` データは自動で実日付へ移行


## ② 曜日ごとの学習負荷調整
- 月：5問・30分（ピアノ）
- 火：2問・15分（国語＋算数2nd）
- 水：6問・40分（通塾なし）
- 木：2問・15分（理科＋社会）
- 金：1問・10分（最レ算数）
- 土：3問・20分（算数1st）
- 日：第1・3週 2問、第2週 1問、第4・5週 4問
- 期限到来が上限を超えた場合も問題は削除せず、待機として翌日以降へ持ち越します。


## ③ もっと可愛い育成要素
- うさぎLv：◎・○・定着で成長
- パンダLv：△・×も含め、挑戦と連続学習で成長
- なかよし度：二人の成長＋連続学習で上昇
- ごほうびコレクション：6種類を条件達成で解放
- 解放アイテムは「おへや」画像の上にも表示
- 今日のおすすめを全部終えると、うさぎ＋パンダのクリア演出を表示
- ランダムガチャではなく、学習成果に応じて確実に解放される設計
